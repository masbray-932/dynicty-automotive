# Admin Dashboard

`/admin` is protected and reports database-backed total, AVAILABLE, DRAFT, SOLD, NEW, USED, and featured counts. Counts/grouping and six recently updated vehicles execute in parallel. Recent rows use the shared title builder, Rupiah/date formatting, deterministic update/ID order, status text, and edit links.

Real zero inventory displays zero metrics plus a first-car CTA. Database failure is an explicit separate state and never invents zero counts. Shortcuts include Add Car, Manage Cars, Dealer Settings, and View Website. Metrics reflow on small screens; the recent table has constrained horizontal scrolling.
