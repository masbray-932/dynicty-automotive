## 2. Schema and SQL review

| Model | Additions |
|---|---|
| `Dealer` | CUID generated by Prisma, globally unique slug, display name, `DealerLifecycle` (`PENDING`, `ACTIVE`, `SUSPENDED`, `ARCHIVED`), created/updated timestamps. Defaults to `PENDING`. The SQL check reserves the legacy ID `default` and rejects blank IDs; a trigger prevents updating a dealer ID even before it has dependents. |
| `DealerDomain` | Required dealer FK; globally unique normalized hostname (max 253 characters); separate verification (`PENDING`, `VERIFIED`, `REVOKED`) and routing (`PENDING`, `ACTIVE`, `SUSPENDED`, `RETIRED`) states. Inactive defaults, optional verification/activation timestamps, canonical flag default false, binding version default 1, created/updated timestamps. Composite unique `(dealerId,id)` for future ownership FKs and index `(dealerId,routingState)` for dealer binding lookups. |
| `DealerSettings` | Adds a nullable unique `dealerId` FK to `Dealer.id`, allowing a later one-to-one mapping. Existing Settings IDs, defaults and fields stay unchanged. Both new ownership FKs use `ON DELETE RESTRICT ON UPDATE RESTRICT`. |

Migration: `prisma/migrations/20261105000000_stage_4c2e1_dealer_registry/migration.sql`. The baseline-to-target Prisma schema diff accounts for the types, tables, indexes, nullable column and FKs. Handwritten SQL adds the checks, trigger, and canonical partial unique index in the same explicit transaction. The only existing table touched is `DealerSettings`: add nullable column (no default), its unique index, and its FK. There are no data writes, destructive DDL, global-unique removals, or required ownership columns on existing rows. All earlier migrations, including the primary-image partial unique index, are unchanged.

The domain check accepts persisted lowercase ASCII DNS hostname syntax with length-bounded labels and a nonnumeric final label, including valid-shaped A-labels. It rejects uppercase, whitespace, trailing dots, ports, wildcards and numeric IP-like hosts. It does not normalize a request or prove that an A-label is valid IDNA or that a hostname is owned. A verified domain needs `verifiedAt`; active routing requires verification and `activatedAt`; a canonical binding must be active; `bindingVersion` must be positive. The partial unique index allows zero or one canonical binding per dealer, independent of concurrency. It does not require one to exist.

## 3. Legacy compatibility and deferred rules

Existing Settings rows, including `id="default"`, retain their primary keys and get an initially NULL association. CMS `dealerId` continues to reference **Settings.id**. Existing Settings/CMS read and write paths still use the same legacy ID; catalog URLs, admin session tables, credentials, theme behavior and stored color/logo columns are unchanged. Prior regressions run with the regenerated client, including single-dealer Settings/CMS, permission separation, and branding write protection. These are source and test checks, not a database backfill rehearsal.

A later transactional service must verify ownership and DNS/TLS before setting state, enforce permitted lifecycle transitions, require an active dealer before routing, switch canonical hosts with the old flag cleared before setting the new one, and ensure exactly one canonical binding for an active dealer. Also deferred: monotonic binding-version changes, domain reservation/transfer and re-verification, suspension and session/cache invalidation, verified legacy mapping and backfill, ownership for inventory/membership, and database isolation. CUIDs and updated timestamps are generated/managed by Prisma, not SQL defaults for direct inserts.

Operational handoff: the old client can continue using the original columns after expansion. A newly generated client may select the new column by default, so a future deployment must apply and verify the additive migration **before** starting a build using that client. Keep additive DDL in place for application rollback; do not deploy or apply migrations from this stage. Validate DDL lock duration on a disposable legacy restore before any live rollout.
